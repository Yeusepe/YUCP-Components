# YUCP UI

Shared Unity Editor UI for YUCP Components and DevTools: inspector builders, window controls, styles, and a material picker. Requires Unity 2022.3 or later.

## Installation

Add `https://vpm.yucp.club/index.json` to VRChat Creator Companion, then install **YUCP UI**. Components and DevTools install it automatically as a required dependency.

For manual installation, download `com.yucp.ui-0.1.0.unitypackage` from the [Components releases](https://github.com/Yeusepe/YUCP-Components/releases). The ZIP is the VPM package.

## Development

This package is maintained and released in the YUCP Components repository. Its editor assembly is `com.yucp.ui.Editor`; it has no dependencies on Components or DevTools. See [DESIGN.md](DESIGN.md) for the shared UI conventions.
